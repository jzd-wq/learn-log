## 核心知识

- 链表由一个个节点组成；
- 每个节点保存两个信息：一个数据值，以及一个指向下一个节点的引用 `next`；
- `head` 指向链表的第一个节点；
- `next` 可以用来访问当前节点的下一个节点；
- `null` 表示当前节点后面没有下一个节点，也表示链表到此结束。

## 链表结构实践

亲手构造出了下面的链表：

```text
10 -> 5 -> 0 -> null
```

其中，`10`、`5` 和 `0` 是节点中保存的数据值，箭头表示节点之间通过 `next` 建立的引用关系。

## 今日代码实践

实现了一个计算链表长度的方法：

```csharp
public int size() {
    if (next == null) {
        return 1;
    }

    return 1 + next.size();
}
```

这段代码作为今天的代码实践记录保留，不在本篇中额外展开后续知识。

## 今日总结

今天理解了链表最基础的组成方式：多个节点通过 `next` 引用连接起来，`head` 作为入口指向第一个节点，而 `null` 表示链表的末尾。通过实际构造 `10 -> 5 -> 0 -> null`，进一步熟悉了节点、数据值和引用之间的关系。
